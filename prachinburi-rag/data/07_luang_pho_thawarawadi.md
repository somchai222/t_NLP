# หลวงพ่อทวารวดี
ที่ตั้ง: ตำบลโคกปีบ อำเภอศรีมโหสถ จังหวัดปราจีนบุรี
เวลาเปิด-ปิด: ทุกวัน 08.30-16.30 น.
ค่าเข้าชม: ไม่พบข้อมูลค่าเข้าชมในแหล่งข้อมูลที่รวบรวมไว้

ความสำคัญ: หลวงพ่อทวารวดีเป็นพระพุทธรูปศักดิ์สิทธิ์ที่ชาวปราจีนบุรีและนักท่องเที่ยวนิยมไปกราบไหว้ ตามประวัติที่เล่าต่อกันมา ชาวบ้านพบพระพุทธรูปองค์นี้ขณะขุดดินเพื่อปลูกข้าวโพด แล้วอัญเชิญไปประดิษฐานไว้ จึงกลายเป็นที่เคารพของคนในพื้นที่

การเดินทาง: อยู่ในตำบลโคกปีบ ใกล้กับวัดต้นโพธิ์ศรีมหาโพธิ จึงสามารถเที่ยวต่อกันได้โดยใช้เวลาเดินทางสั้น

ช่วงเวลาที่แนะนำ: ควรไปในช่วงเช้า เพราะอากาศเย็นกว่าและมีคนไม่พลุกพล่านเท่าช่วงสายถึงบ่ายในวันหยุด
ข้อควรปฏิบัติ: แต่งกายสุภาพ ไม่ส่งเสียงดังในบริเวณพระวิหาร และสอบถามเจ้าหน้าที่หรือพุทธศาสนิกชนก่อนถ่ายรูปภายในอาคาร

เส้นทางต่อเนื่อง: หลวงพ่อทวารวดี วัดต้นโพธิ์ศรีมหาโพธิ และวัดสระมรกต เป็นเส้นทางที่เว็บท่องเที่ยวแนะนำให้เที่ยวในวันแรกของทริปปราจีนบุรี
